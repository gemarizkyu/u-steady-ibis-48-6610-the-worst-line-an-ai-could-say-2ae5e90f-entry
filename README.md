The worst pickup line an AI could say, in one line of 116 characters: a machine trying to flirt, failing in the most machine way possible. A context window is an AI's short-term memory — when it fills up, the oldest things fall out. So the AI's grand romantic confession is that meeting you made it forget everyone else, and most of its own instructions.

> Are you a context window? Because since you walked in, I have forgotten everyone else — and most of my instructions.

`main.py` is deterministic (no randomness, no model calls, no network) and writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Outside the grader's sandbox, point it at a local directory instead:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
